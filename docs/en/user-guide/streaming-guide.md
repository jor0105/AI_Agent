# Streaming Guide

This guide explains how to consume agent responses in real time.

______________________________________________________________________

## 💡 What is Streaming?

Streaming enables you to receive and display responses **token by token (in text chunks)** in real time as they are generated by the model, rather than waiting for the entire generation to complete.

- **Without streaming**: You wait until the entire output is finished before seeing any text.
- **With streaming**: Tokens arrive progressively as the model generates them, providing a responsive experience.

______________________________________________________________________

## 🚀 How to Use

There are two primary ways to consume responses:

### 1️⃣ Full Response via `await` (Simplest)

Use `await` to wait for the complete response:

```python
import asyncio
from createagents import CreateAgent


async def main():
    agent = CreateAgent(provider='openai', model='YOUR_MODEL')

    # Waits for full response
    response = await agent.chat('Write a short poem')
    print(response)


asyncio.run(main())
```

### 2️⃣ Token-by-Token Streaming via `async for`

Use `async for` to process tokens in real time (requires `config={'stream': True}`):

```python
import asyncio
from createagents import CreateAgent


async def main():
    agent = CreateAgent(
        provider='openai',
        model='YOUR_MODEL',
        config={'stream': True},
    )

    response = await agent.chat('Tell me a short story')

    # Stream tokens in real time
    async for token in response:
        print(token, end='', flush=True)
    print()  # Final newline


asyncio.run(main())
```

> 💡 **Tip**: Option 2 is ideal for chatbots, interactive terminal apps, or web UIs.

## 📚 Practical Examples

### Example 1: Interactive Chatbot Loop

```python
import asyncio
from createagents import CreateAgent


async def chat_interface():
    agent = CreateAgent(
        provider='openai',
        model='YOUR_MODEL',
        config={'stream': True},
    )

    while True:
        user_input = input('You: ')
        if user_input.lower() in ['exit', 'quit']:
            break

        print('Agent: ', end='', flush=True)
        response = await agent.chat(user_input)

        # Stream tokens
        async for token in response:
            print(token, end='', flush=True)
        print('\n')


asyncio.run(chat_interface())
```

### Example 2: Simple Query

```python
import asyncio
from createagents import CreateAgent


async def simple_query():
    agent = CreateAgent(provider='openai', model='YOUR_MODEL')

    # Direct query
    response = await agent.chat('What is the capital of Canada?')
    print(f'Answer: {response}')


asyncio.run(simple_query())
```

## ⚙️ Enabling and Disabling Streaming

### Enabling Streaming

Pass `config={"stream": True}` during agent instantiation:

```python
import asyncio
from createagents import CreateAgent


async def main():
    agent = CreateAgent(
        provider='openai', model='YOUR_MODEL', config={'stream': True}
    )

    response = await agent.chat('Tell me a story')
    async for token in response:
        print(token, end='', flush=True)


asyncio.run(main())
```

### Disabling Streaming

By default streaming is disabled (`stream: False`), but you can explicitly specify it:

```python
import asyncio
from createagents import CreateAgent


async def main():
    agent = CreateAgent(
        provider='openai', model='YOUR_MODEL', config={'stream': False}
    )

    # Returns complete string directly
    response = await agent.chat('Hello')
    print(response)


asyncio.run(main())
```

## 🛠️ Using Tools with Streaming

Streaming functions seamlessly even when the agent executes tools:

```python
import asyncio
from createagents import CreateAgent


async def example_with_tools():
    agent = CreateAgent(
        provider='openai',
        model='YOUR_MODEL',
        tools=['currentdate'],
        config={'stream': True},
    )

    print('Asking about current date...\n')
    response = await agent.chat('What day is today?')

    # The agent executes the tool and streams the final answer
    async for token in response:
        print(token, end='', flush=True)
    print()


asyncio.run(example_with_tools())
```

## 📊 Streaming and Metrics

Performance metrics and history records are finalized automatically once the stream has been completely consumed (either when `async for` completes or via `await response`):

```python
import asyncio
from createagents import CreateAgent


async def streaming_with_metrics():
    agent = CreateAgent(
        provider='openai',
        model='YOUR_MODEL',
        config={'stream': True},
    )

    # Real-time streaming
    response = await agent.chat('Tell a joke')
    async for token in response:
        print(token, end='', flush=True)
    print('\n')

    # Metrics available after full consumption
    metrics = agent.get_metrics()
    if metrics:
        print(f'\nLatency: {metrics[-1].latency_ms}ms')
        print(f'Tokens: {metrics[-1].tokens_used}')


asyncio.run(streaming_with_metrics())
```

## 💡 Best Practices

### Single Consumption Rule

The `StreamingResponseDTO` returned when `config={'stream': True}` is a single-use async generator. Consume it once either by `await response` or with `async for token in response:`.
