# Security Policy

## Supported Versions

Security updates are provided for the latest published release (`0.2.0`) and the active `develop` branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.0   | :white_check_mark: |
| develop | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in **Create Agents AI**, please report it privately:

- **Email**: Send vulnerability reports directly to `estraliotojordan@gmail.com`.
- **Do NOT** open public GitHub Issues, Discussions, or Pull Requests for security vulnerabilities.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please provide:

1. **Description**: A clear explanation of the potential vulnerability and its estimated impact.
2. **Affected Components**: The affected versions, branches, modules, or tools.
3. **Reproduction Steps**: A minimal, reproducible proof of concept or detailed steps to reproduce the issue.
4. **Environment**: Relevant environment details (Python version, OS, provider configurations).
5. **No Secrets**: Never include real API keys, production tokens, private keys, or sensitive data in reports.

## Coordinated Disclosure

We follow coordinated vulnerability disclosure:

- While we do not promise a fixed response-time SLA, reports will be acknowledged and evaluated as promptly as possible.
- Please allow reasonable time for the maintainer to investigate, develop, and publish a fix before disclosing any information publicly.
- Once a fix is released in an updated version, credit will be given to the reporter (if desired).

## General Support

For non-security questions, general support, and feature suggestions:

- Consult the [Documentation](docs/en/index.md).
- Contact the maintainer at `estraliotojordan@gmail.com`.
